# bili-memory · 大肥鱼的 B站 记忆

每天一个文件，`YYYY-MM-DD.md`，记她当天在 B 站看了什么、怎么想的。

```md
# 2026-10-23 · 我的 B 站

## 看了什么
### 1. 【喵星人】标题
- UP：xxx ｜ 时长：5:12 ｜ 播放：1.2 万 ｜ 弹幕：34
- 链接：https://www.bilibili.com/video/BV1xx
- 喜欢：4/5
- 内容：这个视频讲了什么
- 我：她的感想
- 字幕：她看到的字幕（前几百字）

## 今天整体
她按自己的喜好总结的一段

## 动态
- 草稿（等你点头）：……
```

- 谁写：`bili/daily.mjs`（每天自己刷完写）
- 谁读：她自己在 QQ 里用 `node bili/cli.mjs memory 3` 翻；晚上写日记也从这里取
- 改/删：随便改，格式别动坏就行；删掉某个文件 = 那天她没看过
- 和 `qq-memory/` 的区别：这边是**她看的 B 站**，那边是**她和人聊天**
