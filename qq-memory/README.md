# qq-memory · 大肥鱼的 QQ 聊天记忆

这里按天存她和 QQ 上每个人的聊天记录，一天一个文件，人能直接读、直接改。

```
qq-memory/
├── README.md          ← 这个文件
├── 2026-10-23.md
├── 2026-10-22.md
└── ...
```

每行一条：

```
- 14:39 [私聊 123456789] 张三：在干什么
- 14:39 [私聊 123456789] 我：在发呆呢，顺便想你啥时候会来找我说话。
```

`[私聊 12345]` / `[群 67890]` 是会话标记，`我：` 表示是她说的。

## 聊天时是怎么用的

桥接（`qq-bridge/bridge.mjs`）每条消息会：

1. 把**最近 7 天**（含今天）的记录拼在消息前面，当提示词带进去 —— 只带这个会话自己的记录（号主私聊能看到全部）；
2. 如果对方这句话里提到了具体哪天（`昨天` `前天` `3天前` `上周三` `10月15日` `2026-10-01` `10/15` 这些写法都认），
   就把那一天的记录单独读出来，放进「另外翻到的更早记录」；
3. 消息和她自己的回复，各追加一行到当天文件。

一周以外的日子不会自动带，但她可以自己用 fs 读 `qq-memory/2026-09-30.md`。

## 想改 / 想让她忘

- **改记忆**：直接编辑当天的 `.md`，格式保持 `- HH:MM [会话] 说话人：内容` 就行，不用重启（每次聊天都会重新读）。
- **让她忘掉某一天**：删掉那个文件。
- **让她忘掉某个人**：只删对应会话的行，或者删掉 `qq-bridge/state.json` 里那条 `p:<QQ号>` / `g:<群号>`（下次会开新会话）。
- **不想让她带记忆**：`qq-bridge/config.json` 里 `memory.enabled` 设成 `false`，或者 `days` 调小。

## 配置（`qq-bridge/config.json` → `memory`）

| 键 | 默认 | 作用 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `dir` | `qq-memory` | 存哪儿；相对路径按工作区（`agent.cwd`）算 |
| `days` | `7` | 每次带最近几天 |
| `perDayChars` | `2200` | 一天最多带多少字，超了留最近的 |
| `totalChars` | `9000` | 整段记忆上限（约 4~5k token） |
| `maxMsgChars` | `600` | 单条消息超过就截断 |

## 隐私

文件是明文，谁拿到这个工作区谁都能看。群聊只会带这个群自己的记录，不会把私聊内容漏进群里。
